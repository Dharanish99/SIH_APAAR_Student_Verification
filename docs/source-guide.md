# Source guide and setup references

These are starting points, not a completed evidence register. Each owner must inspect the relevant version/section and record claim-level evidence in their own sources.csv.
Planning discovery date: **2026-10-23**. Do not treat this date as the publication date of a source.

## Project and domain sources
| ID | Source | Use / limitation |
|---|---|---|
| S01 | [Supplied SIH26263 page](https://zaidsayyed.in/tools/sih-problem-statements/sih26263) | Third-party problem text; official wording and event dates require confirmation |
| S02 | [APAAR official FAQs](https://apaar.education.gov.in/faqs) | Identity ecosystem; distinguish school-specific processes from higher education |
| S03 | [Academic Bank of Credits](https://www.abc.gov.in/) | Investigate credit/identity workflows and official documentation |
| S04 | [DigiLocker NAD FAQs](https://nad.digilocker.gov.in/faq) | Academic awards, institutional responsibilities and verification |
| S05 | [DigiLocker implementation model](https://www.digilocker.gov.in/web/implementation-model) | Investigate partner onboarding; verify current access and technical documentation |
| S06 | [AICTE Approval Process Handbook](https://www.aicte.gov.in/sites/default/files/APH%20Final.pdf) | Base handbook; locate applicable addenda/corrigenda and institution-specific approvals |
| S07 | [UGC guidelines listing](https://www.ugc.gov.in/Guideline) | Find original and modified simultaneous-programme guidance |
| S08 | [MeitY DPDP Rules and notifications](https://www.meity.gov.in/documents/act-and-policies/digital-personal-data-protection-rules-2025-gDOxUjMtQWa) | Read final text, corrigendum and enforcement timeline; establish applicability |

An unavailable page is a limitation, not permission to invent its contents. Record the failure and seek an official alternative.
