## Before the team submits

- Confirm current official problem wording and the portal's exact required fields/formats.
- Run `npm ci`, `npm run check` and the timed walkthrough on the presentation laptop.
- Confirm team details through the human lead and record actual review feedback.
- Use only fictional data in the demonstration and describe providers/authentication/approvals as simulated.
- Present the tested correction/reporting/disclosure loop; do not claim an authorised integration, field pilot or official credential.
